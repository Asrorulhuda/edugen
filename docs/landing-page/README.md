# EduGen KBC Landing Page

Static reference implementation for the public landing page.

## Files

- `index.html`
- `styles.css`
- `app.js`

## Principles

- mobile-first and responsive from 360px upward;
- asymmetric bento layout;
- restrained editorial visual system, not generic AI-SaaS styling;
- subtle reveal/workflow interaction with `prefers-reduced-motion` support;
- no fabricated users, schools, ratings, testimonials, usage counts, validation percentages, prices, or other operational data;
- real product copy only; where live data is unavailable, the UI explains capability rather than inventing numbers;
- production app should port this visual direction to React/Inertia and wire CTA/routes to real onboarding/auth.

Open `index.html` directly in a browser for the static reference.
